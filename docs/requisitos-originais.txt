# 6. SEGURANÇA

Requisitos obrigatórios:

- Autenticação administrativa com senha criptografada usando Argon2id.
- Sessões seguras em cookies HttpOnly, Secure e SameSite.
- Proteção CSRF para ações autenticadas.
- Controle de acesso administrativo.
- Rate limiting.
- Proteção contra brute force.
- Validação de arquivos enviados.
- Controle de tamanho e formato dos uploads.
- Proteção contra XSS.
- CORS restritivo.
- Logs de auditoria.
- Variáveis de ambiente para segredos.
- HTTPS.
- Nenhuma chave exposta no frontend.
- Backup e procedimento de restauração.

Não criar contas administrativas com senhas fixas no repositório.

Fornecer procedimento seguro para criação do primeiro administrador via terminal.
