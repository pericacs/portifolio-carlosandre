# CODEX — IMPLEMENTAR PAINEL ADMINISTRATIVO DO PORTFÓLIO

## OBJETIVO

Implementar um CMS administrativo completo para o projeto **Carlos André | Technology & Ventures**, permitindo editar, cadastrar, excluir, organizar, pré-visualizar e publicar os conteúdos sem alterar código.

**ATENÇÃO: O SITE PÚBLICO JÁ POSSUI UM DESIGN APROVADO. NÃO ALTERAR SEU LAYOUT, CORES, TIPOGRAFIA, IMAGENS, ESPAÇAMENTOS OU COMPOSIÇÃO VISUAL.**

Implementar o painel administrativo e substituir gradualmente o conteúdo estático por dados persistidos no PostgreSQL, preservando a aparência atual.

## FASE 1 — INSPEÇÃO E SEGURANÇA

Antes de começar:

1. Inspecionar toda a estrutura existente do repositório.
2. Identificar frontend Next.js, API FastAPI, PostgreSQL, Docker e migrações existentes.
3. Reaproveitar os componentes, serviços, bibliotecas e padrões já implementados.
4. Identificar quais dados estão atualmente fixos no código.
5. Criar um plano de migração do conteúdo estático para o banco de dados.
6. Preservar todo o conteúdo e os arquivos originais.
7. Não apagar nem recriar tabelas que já contenham informações.
8. Não modificar a Home visualmente.

Criar uma cópia de segurança antes de executar migrações que alterem estruturas existentes.

## FASE 2 — ACESSO ADMINISTRATIVO

Criar:

`/admin/login`

`/admin`

Implementar autenticação segura com:

- Usuário administrador.
- Senha com hash Argon2id.
- Sessão protegida por cookie HttpOnly, Secure em produção e SameSite.
- Proteção CSRF.
- Limitação de tentativas de login.
- Logout.
- Recuperação de senha por e-mail, quando SMTP estiver configurado.
- Proteção das rotas administrativas no backend.
- Registro de operações administrativas.

Criar comando CLI para cadastrar o primeiro administrador, sem senhas fixas no código.

Não disponibilizar cadastro público de administradores.

## FASE 3 — DASHBOARD

Criar uma interface profissional com menu lateral, dashboard e módulos administrativos.

A tela principal deve mostrar:

- Quantidade de projetos.
- Artigos publicados e em rascunho.
- Vídeos cadastrados.
- Experiências profissionais.
- Mensagens recebidas.
- Últimos conteúdos alterados.
- Publicações agendadas.
- Visitas, somente quando houver integração real com analytics.

Não utilizar métricas fictícias.
